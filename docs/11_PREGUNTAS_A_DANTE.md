# 11 · Preguntas creativas para hacerle a Dante

No hace falta preguntar todo junto. Conversar mientras mira los personajes y **anotar sus palabras tal cual**.

## Primera charla (5 minutos)

1. **«¿Cómo se escribe el nombre de tu robot: Pattha, Pata o de otra forma?»**
2. **«¿Cómo se llama el ratoncito verde?»**
3. **«¿A dónde quieren ir Pattha, Rural y su amigo?»**
4. **«¿Qué cosa superespecial sabe hacer Pattha?»**
5. **«¿Qué cosas saben hacer los dos ratones?»**

## Segunda charla (cuando haya una demo)

- «¿El robot salta, vuela, corre o hace algo distinto?»
- «¿Los ratones lo siguen o también querés controlarlos?»
- «¿Qué pasa cuando ganan una pantalla?»
- «¿Hay alguien a quien ayudar o algo que encontrar?»
- «¿Qué te gusta más de cómo se ven? ¿Qué cambiarías?»

## Cómo registrar el canon

Completar este pequeño formato en `docs/01_VERDADES_Y_DECISIONES.md`:

```text
Fecha:
Dante dijo literalmente:
Decisión confirmada por la familia:
Afecta a (historia / personaje / color / mecánica / controles):
Archivos a actualizar:
```

Nunca usar una idea divertida de una IA como si fuera una decisión de Dante.

# Entrega compilada web · 0.1

La carpeta web/ contiene el juego listo para servir por HTTP. Está versionada por pedido de la familia junto al código y assets. Para regenerar: pnpm build desde la raíz. Para probar el build: pnpm preview → localhost:4173. No abrir index.html con file://.

No hay hosting público ni aplicación instalable. En mobile, usar navegador horizontal y botones táctiles. README raíz documenta acceso por Wi-Fi local.

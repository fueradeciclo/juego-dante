# PROMPT MAESTRO — iniciar proyecto PATTHA en Codex

Quiero que seas mi socio de desarrollo para crear un videojuego familiar a partir de los **dibujos originales de mi hijo Dante**. El protagonista es el robot **Pattha** (validar su grafía final), acompañado por dos ratones amigos: uno verde, sin nombre confirmado, y **Rural**, azul. Ya contamos con ilustraciones digitales cartoon y un kit de documentación.

**Objetivo:** transformar este material en un juego real, entregable por etapas, con una primera demo pequeña para jugar juntos y tomar decisiones con Dante.

**INSTRUCCIONES IMPORTANTES:**

1. Antes de escribir código, leé de principio a fin `AGENTS.md`, `README.md`, `docs/01_VERDADES_Y_DECISIONES.md`, `docs/02_VISION_Y_DISENO.md`, `docs/03_PERSONAJES.md`, `docs/05_MVP_Y_CONTROLES.md`, `docs/08_TECNOLOGIA_Y_EXPORTACION.md` y `assets/MANIFEST.json`. El resto de docs sirve como propuesta editable; no lo trates como historia oficial.
2. **No supongas Godot, Unity ni ninguna otra plataforma.** Presentame una tabla breve comparando al menos 3 alternativas viables para nuestros objetivos; incluí posibilidad de jugar en navegador, exportación a dispositivos, curvas de aprendizaje, costos/licencias a verificar y aptitud para animación 2D cartoon. Considerá, según corresponda, Godot, Phaser, GDevelop, Unity, Construct o una solución web propia. Explicá una recomendación condicional (según mis respuestas), no una imposición.
3. Primero haceme **hasta tres preguntas esenciales** que afecten de verdad la arquitectura: (a) ¿dónde queremos jugar?, (b) ¿qué género o experiencia imaginamos?, (c) ¿preferimos editar visualmente escenas o nos resulta bien código? Si la respuesta existe en los archivos, no la repitas.
4. Repetí lo que es **CANON CONFIRMADO** frente a las **IDEAS PROPUESTAS**, especialmente sobre el argumento, las habilidades y el nombre del ratón verde. Preguntá a Dante lo importante con lenguaje sencillo.
5. Una vez que elijamos tecnología, creá el esqueleto del proyecto y un vertical slice jugable de 5–10 minutos: pantalla inicial, Pattha controlable, ratones presentes, diálogo y un obstáculo resuelto con cooperación sencilla. Permití usar los PNG recortados como placeholders; no afirmes que son spritesheets.
6. Garantizá estructura de carpetas clara, assets aislados del código, controles documentados, instrucciones `run`/`build`, README actualizado y criterios de aceptación testeados.
7. Usá español argentino en los textos, estilo amable e inclusivo y dificultad apta para familias. No uses anuncios, compras dentro del juego, cuentas online ni servicios externos sin consentimiento.
8. Hacé una entrega incremental: lista de tareas, implementación, pruebas, captura/preview si se puede y próximos pasos. Dejá TODO registrado en este repositorio para que podamos continuar en futuras sesiones.

**Tu primera respuesta ahora:** confirmá qué archivos encontraste, hacé la comparación tecnológica concisa, listá las decisiones pendientes críticas y proponé las primeras 3 tareas. **No programes todavía hasta acordar destino y género del juego.**
